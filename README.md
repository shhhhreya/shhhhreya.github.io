# Shreya Singh — Portfolio

A responsive, static personal portfolio built with HTML, CSS and vanilla JavaScript. Designed for GitHub Pages.

## Before publishing
1. In `index.html`, replace `YOUR_EMAIL@example.com` with your public contact email.
2. Confirm the GitHub and LinkedIn URLs.
3. Replace project links with the exact repositories.
4. Review the experience wording and add dates/impact only if accurate.
5. Add a PDF resume to `assets/` and link it if you want a resume download.

## Publish at `https://ShreyaUwU.github.io`
1. Create a **public** GitHub repository named exactly `ShreyaUwU.github.io` (the username must match your GitHub account's exact casing/spelling).
2. Upload all files and folders from this project to the repository root (so `index.html` is at the root).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for GitHub Pages to finish deploying. Your site will appear at `https://ShreyaUwU.github.io`.

## Local preview
Open `index.html` in a browser, or run a local static server from this folder:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.
